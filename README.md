# ReportingApp - Transtu

Application de signalement pour le transport public Transtu : une API backend (Spring Boot) et une application mobile (Flutter) permettant aux voyageurs de créer des signalements et de suivre leur traitement, avec back-office pour les agents/administrateurs.

## Développement

Le développement est actuellement actif sur la branche **`develop`**.
